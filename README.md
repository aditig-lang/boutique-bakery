# 🧁 Boutique Bakery

A practice bakery website showcasing handcrafted cakes, specialty desserts, and bakery offerings with a clean, responsive web design.

---

## 🌟 Features

* **Interactive Product Pages:** Dedicated detail pages for individual bakery creations including:
  * Classic Carrot Cake
  * Dark Chocolate Torte
  * Lavender Honey Cake
  * Lemon Raspberry Cake
  * Matcha Sponge Cake
* **Responsive Styling:** Custom CSS layout designed to adapt smoothly across mobile and desktop devices.
* **Custom Error Handling:** Includes a styled `404.html` fallback page for invalid routes.
* **Node.js Express Server:** Simple local server setup to serve static assets and HTML views seamlessly.

## 🚀 Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v14 or higher)
* [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/aditig-lang/boutique-bakery.git](https://github.com/aditig-lang/boutique-bakery.git)
   cd boutique-bakery
Install dependencies:

Bash
npm install
Start the server:

Bash
node server.js
View in browser:
Open http://localhost:3000 (or the port logged in your terminal) to explore the site.
